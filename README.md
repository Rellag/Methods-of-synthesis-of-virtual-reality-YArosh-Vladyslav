# PA#1 — WebGL Stereo Camera (Anaglyph)

Лабораторна робота #1 з курсу *Methods of synthesis of virtual reality*
(КПІ, кафедра ОТ). Анагліфне (червоно-ціанове) стереозображення
параметричної поверхні з вебкамерою у площині нульового паралаксу.

## Що зроблено

1. **Анагліфний стерео-рендер**: модель малюється у негативному
   паралаксі (виходить з екрану на спостерігача), у каркасі поверх
   зафарбованих полігонів. Лівий кадр пише у червоний канал,
   правий — у ціановий (G+B).
2. **Off-axis (асиметрична) перспектива** для лівого та правого ока
   (формули Пола Борка з лекційного PDF). Реалізована у
   `StereoCamera.js`.
3. **Налаштування у реальному часі** через повзунки: eye separation,
   FOV, near clipping, convergence.
4. **Стрім з вебкамери** через `getUserMedia` накладається на quad
   у площині нульового паралаксу (на convergence-площині).
   Рендериться обома очима з однаковою симетричною проекцією, тому
   сприймається як «у площині екрана».
5. **Обертання моделі мишею** навколо центру мас через
   `TrackballRotator` зі стартового коду.

## Поверхня

Замість заглушки-циліндра використана **поверхня Сіверта** (Sievert's
surface) — параметрична поверхня сталої гауссової кривини з курсу VGGI.
Параметризацію легко замінити — див. функцію `sievertPoint()` у
`Model.js`.

## Як запустити

`getUserMedia` працює тільки з HTTPS або з `http://localhost`, тому
просто відкрити файл подвійним кліком не вийде — треба локальний
HTTP-сервер. Наприклад:

```bash
# Python 3
python3 -m http.server 8000
# або Node.js:
npx http-server -p 8000
```

Потім відкрити `http://localhost:8000/` у браузері, дозволити доступ
до вебкамери (кнопка **Start webcam**) і одягти червоно-ціанові
анагліфні окуляри (червоне скло — на ліве око).

## Структура файлів

```
PA1/
├── index.html             — canvas + GUI + прихований <video> для вебкамери
├── shader.gpu             — два GLSL шейдери: solid colour + textured
├── StereoCamera.js        — клас з off-axis frustum (Bourke)
├── Model.js               — Sievert's surface + Quad для вебкамери
├── main.js                — ініціалізація, рендер-цикл, GUI events
└── Utils/
    ├── m4.js              — матрична математика (з starter code)
    └── trackball-rotator.js — обертання сцени мишею
```
